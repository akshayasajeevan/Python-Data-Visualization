# Python Data Visualization | Exploratory Data Analysis

A Python-based data visualization project exploring taxi trip data through statistical plots and graphical analysis using Pandas, Seaborn, and Matplotlib.

## Project Overview

This project focuses on exploring and visualizing the Seaborn Taxi dataset to understand fare distributions, trip characteristics, payment methods, and relationships between numerical variables. A variety of visualizations are used to identify patterns, compare categories, and communicate data insights effectively.

## Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Data Manipulation:** Pandas
- **Visualization:** Seaborn, Matplotlib
- **Dataset:** Seaborn Taxi Dataset

## Visualizations Implemented

| Visualization | Purpose |
|---|---|
| Line Plot | Explore changes in fare over time |
| Bar Plot | Compare total fares across pickup boroughs |
| Pie Chart | Examine payment method distribution |
| Histogram | Understand trip distance distribution |
| Box Plot | Analyze tip distributions by pickup borough |
| Count Plot | Compare trip counts across pickup boroughs |
| Scatter Plot | Explore the relationship between distance and fare |
| Correlation Heatmap | Examine correlations among numerical variables |
| Pair Plot | Visualize pairwise relationships among numerical variables, grouped by pickup zone |
| Violin Plot | Compare fare distributions across payment methods |

## Getting Started

### Prerequisites

Python 3.x and Jupyter Notebook.

### Installation

Install the required libraries:

```bash
pip install pandas seaborn matplotlib
```

### Run the Project

1. Clone or download this repository.
2. Open the `.ipynb` notebook in Jupyter Notebook.
3. Execute the cells in sequence to reproduce the visualizations.
